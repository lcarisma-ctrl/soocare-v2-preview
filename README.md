# 수케어 통합관리 v2 — 미리보기 (빌드 산출물)

이 저장소에는 **빌드된 정적 파일만** 있습니다(소스 코드·개인정보·비밀키 없음).

- 앱을 열면 로그인 화면이 나옵니다. 센터 계정으로 로그인해야 데이터가 보입니다.
- 데이터베이스는 RLS(행 수준 보안)로 잠겨 있어, 로그인하지 않은 방문자는 환자 정보를 읽을 수 없습니다.
- 빌드에 포함된 키는 Supabase **publishable(anon)** 키 하나뿐이며, RLS 가 모든 테이블 접근을 거부합니다.
- 소스: 비공개 저장소 `lcarisma-ctrl/soocare-app-v2`
